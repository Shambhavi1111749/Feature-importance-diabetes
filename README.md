# Feature Importance Analysis in Diabetes Prediction

## Overview
This project analyzes which features most influence diabetes prediction using statistical and machine learning methods.

## Objective
To compare different feature importance techniques and understand how they differ in capturing relationships in healthcare data.

## Methods Used
- Correlation Analysis
- Random Forest Feature Importance
- Permutation Importance

## Key Findings
- Glucose is the strongest predictor across all methods
- BMI is consistently important
- Blood Pressure shows variation across methods
- Age contributes through interactions

## Why This Matters
Understanding feature importance improves interpretability and helps build reliable healthcare systems.

## Dataset
Pima Indians Diabetes Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
